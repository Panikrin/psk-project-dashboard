# Синхронизация TickTick → ПСК

Импорт односторонний: сайт только читает выбранные рабочие списки TickTick.
Изменения на сайте не отправляются обратно в TickTick. Локальные поля сохраняются,
пока соответствующее поле не изменится в источнике. Этапы, план/факт, таймеры и
подзадачи сайта сохраняются при импорте. Отсутствие задачи в активном списке само
по себе не означает выполнение. Заметки не импортируются.

Токен TickTick хранится только в серверной базе, зашифрован AES-GCM с отдельным
runtime-секретом PSK_SYNC_KEY. Пароль команды состоит ровно из шести цифр и хранится в виде PBKDF2-хеша с солью.
Сеансы хранят только хеш случайного токена; cookie HttpOnly, Secure, SameSite=Lax,
срок семь дней. Смена пароля отзывает все сеансы. Настройки подключения доступны
только владельцу через проверенную платформой учётную запись.

Фоновое обновление выполняет GitHub Actions: один запуск в час и ручной запуск.
GitHub может задерживать плановые запуски. В публичных репозиториях GitHub может
приостановить расписание после длительного отсутствия активности.

Секрет GitHub `PSK_SYNC_SERVICE_KEY` должен совпадать с runtime-секретом сайта
`PSK_SERVICE_SYNC_KEY`. Он разрешает только POST/GET `/api/ticktick/sync`, не чтение
задач и не редактирование настроек. Не сохраняйте его в коде, файлах, логах и URL.
Workflow запускается только при repository variable `SYNC_ENABLED=true`.
Включать после настройки пароля и публичного доступа к странице входа.

Обновление использует блокировку, минимальный интервал и контроль ревизии. После
записи workflow проверяет сохранённые статус, время и количество задач. Ошибка
источника сохраняет последние хорошие данные. Не переподключайте источник и не
очищайте данные автоматически при временных сбоях.

В базе нет публичного доступа. `/api/dashboard`, `/api/projects`, `/api/media`
доступны вошедшей команде и владельцу. `/api/admin` и управление TickTick — только
владельцу. Папки Google Диска привязываются владельцем к проектам в `/settings`.
Доступ и загрузка в эти папки регулируются Google Диском. Файлы в старом хранилище
R2 и фотографии обложек сохранены отдельно от импорта.

Исходники содержат пустой начальный список. Рабочие задачи, пароли, токены, ссылки
на папки и локальная история не включаются в публичный репозиторий.

## Интерфейс GitHub Pages

Адрес команды: https://panikrin.github.io/psk-project-dashboard/ . Это полноценный
статический интерфейс с тем же сервером задач. После проверки шестизначного кода
сервер выдаёт случайный токен сеанса; GitHub-страница хранит его в sessionStorage
и передаёт только серверу ПСК в Authorization. Перезагрузка сохраняет вход в этой
вкладке. Закрытие вкладки удаляет локальное хранилище, выход отзывает сеанс на
сервере, смена пароля отзывает все сеансы. Пароль не сохраняется в браузере кодом
приложения. Cookie-путь для исходного сайта продолжает работать отдельно.

CORS ограничен origin `https://panikrin.github.io`. Настройки владельца не
доступны по токену команды. Медиа R2 передаются с авторизацией и показываются
через локальные blob URL; ключи и токены не включаются в URL запросов.
