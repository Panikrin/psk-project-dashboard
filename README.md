# ПСК — проекты и задачи

Рабочая панель ПСК: обзор проектов, задачи и подзадачи, сроки, диаграмма Ганта,
проценты выполнения, план/факт и медиа проектов в Google Диске.

[Открыть сайт](https://panikrin.github.io/psk-project-dashboard/)

Сотрудники входят по паролю команды. Изменения сохраняются в общей серверной базе;
открытые страницы получают обновления автоматически. Конфликты одновременного
редактирования проверяются по ревизии. Настройки пароля, TickTick и папок Google
Диска доступны владельцу на отдельной странице.

В этом репозитории только исходный код с чистой историей. Рабочие задачи, файлы,
пароли и ключи сюда не выгружаются. База D1 и хранилище R2 находятся у сайта.
Интерфейс публикуется из `docs/` на GitHub Pages. Сервер задач, настройки владельца,
TickTick и база остаются в Sites. Сайт на GitHub сохраняет изменения в этой же базе.
Runtime-секреты управляются отдельно от публичного репозитория.

## Разработка и проверки

Node.js 22.13+; зависимости устанавливаются через `npm ci`.
`npm run dev` запускает локальный предпросмотр. Миграции находятся в `drizzle/`.
`node scripts/embed-dashboard.mjs` обновляет HTML-модуль после правок интерфейса.
`node --experimental-strip-types scripts/check-dashboard.mjs` проверяет план/факт,
таймеры и подзадачи. `node scripts/check-ticktick.mjs` проверяет правила импорта.
`npm run build` собирает Worker.

Подробнее: [синхронизация и доступ](TICKTICK-SYNC.md).

## Обновление интерфейса GitHub Pages

`node scripts/build-pages.mjs` создаёт статические страницы и копирует шрифты в
`docs/`. После изменений HTML нужно запускать эту сборку перед публикацией.
Вход использует серверную проверку кода и случайный токен сеанса в sessionStorage;
код команды и токен TickTick в статические файлы не попадают. Запросы разрешены
только с собственного сайта и origin `https://panikrin.github.io`. Владелец входит
в настройки отдельно через Sites.
